Core structure

  

    

      
Program structure

      
Algorithme Bonjour
Début
  Ecrire("Bonjour")
Fin

    

    

      
Variables

      
Variables
age : entier
nom : chaine

    

    

      
Input and output

      
Lire(age)
Ecrire("Age : ", age)

    

    

      
Condition

      
Si age >= 18 Alors
  Ecrire("Majeur")
Sinon
  Ecrire("Mineur")
FinSi

    

    

      
For loop

      
Pour i de 1 à 5 Faire
  Ecrire(i)
FinPour

    

    

      
While loop

      
TantQue i <= 5 Faire
  Ecrire(i)
  i ← i + 1
FinTantQue
